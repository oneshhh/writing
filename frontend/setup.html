Deployment Configuration

Use a hosted Supabase project or a self-hosted/local Supabase stack. The application expects Supabase Auth plus a PostgreSQL database connection for schema bootstrapping.

Use either the full database URL above or the host/port fields below. This lets teams run the same app against hosted PostgreSQL, self-hosted Supabase, or a local Docker-based Postgres service.
Production tip: prefer real environment variables on your server. The setup page can write a local runtime config file for convenience, but that file contains secrets and should stay private to your deployment.

Optional Integrations

AI detection and deployment tokens are optional. The application can run without them.
